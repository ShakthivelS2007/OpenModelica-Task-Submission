# Model executable

Place the compiled `TwoConnectedTanks` executable here, along with every
file OMEdit generated next to it that it needs at runtime, for example:

- `TwoConnectedTanks` (or `TwoConnectedTanks.exe` on Windows)
- `TwoConnectedTanks_init.xml`
- Any `.dll` / `.so` files OMEdit generated alongside the executable
- Any other dependent files produced by the build (see Part 1 in the root
  README for how these are generated)

Do not rename these files — the executable expects its companion files to
sit next to it with their original names.
